# ⚡ TIMBLOGPLAY AI — FINAL 1.0

**Финальная пользовательская сборка персонального AI-агента TIMBLOGPLAY AI.**

Это самостоятельное веб-приложение: один сервер + браузерный интерфейс. Поэтому им можно пользоваться с **ПК и телефона**, если сервер запущен на компьютере или размещён онлайн.

## Что умеет

- 🤖 AI-чат с многошаговым агентом
- 🔎 веб-поиск с URL источников
- 🧠 долговременная память
- 📁 загрузка и анализ TXT/MD/JSON/CSV/PDF/DOCX и файлов кода
- 🖼️ анализ изображений через vision-совместимую модель
- 🧮 калькулятор
- ⛏️ Minecraft Java команды
- 🖥️ опциональное выполнение команд Minecraft через RCON
- 🗂️ проекты и отдельные рабочие пространства
- 💬 сохранение чатов
- 📱 адаптивный мобильный интерфейс + PWA manifest
- 🔌 Hugging Face / OpenAI / OpenAI-compatible / Ollama
- 🔐 API-ключ модели хранится на сервере, а не в браузере
- 🔒 APP_PASSWORD для защиты веб-приложения при публикации в интернет

## Важное уточнение про «собственную модель»

TIMBLOGPLAY AI — твой собственный AI-продукт/агент и его интерфейс, память, инструменты и данные принадлежат твоей установке. **Модель, которая генерирует ответы, подключается через выбранного провайдера.** Это не означает, что в ZIP уже лежат обученные с нуля веса новой нейросети.

Обучение отдельной базовой модели с нуля — другой проект: нужны датасет, веса, GPU/серверы и длительное обучение. Архитектура этого приложения оставляет возможность позже подключить свою модель через OpenAI-compatible API или Ollama.

# 🚀 БЫСТРЫЙ ЗАПУСК НА WINDOWS

### 1. Установи Node.js 20+

Скачай Node.js с официального сайта:
https://nodejs.org/

После установки перезапусти проводник/терминал, если Windows ещё не видит `node`.

### 2. Распакуй ZIP

Распакуй архив в обычную папку, например:

`C:\TIMBLOGPLAY_AI`

### 3. Настрой AI

Сделай копию `.env.example` с названием `.env`.

Минимальная настройка для Hugging Face:

```env
PROVIDER=huggingface
HF_TOKEN=ТВОЙ_КЛЮЧ
MODEL=openai/gpt-oss-120b:fastest
PORT=3000
APP_PASSWORD=придумай_пароль
```

Не публикуй `.env` и никому не отправляй `HF_TOKEN`.

### 4. Запусти

Просто дважды нажми:

`START.bat`

При первом запуске программа сама установит зависимости.

После запуска открой:

`http://localhost:3000`

Если окно браузера не открылось автоматически — введи этот адрес вручную.

### 5. Если включён APP_PASSWORD

При первом запросе приложение попросит пароль из `.env`.

# 📱 КАК ПОЛЬЗОВАТЬСЯ С ТЕЛЕФОНА

Если AI запущен только на твоём ПК, телефон не сможет обратиться к нему через `localhost` — это адрес самого устройства.

Для доступа с телефона нужен один из вариантов:

1. разместить TIMBLOGPLAY AI на облачном сервере/хостинге;
2. использовать публичный URL платформы вроде Replit;
3. настроить безопасный сетевой доступ к своему ПК.

Для публичного размещения **обязательно оставь `APP_PASSWORD` включённым**.

---

# ☁️ ЗАПУСК НА REPLIT

1. Создай новый Replit-проект с Node.js.
2. Загрузи содержимое этой папки.
3. Добавь Secrets/Environment Variables:

`PROVIDER`
`HF_TOKEN` или `OPENAI_API_KEY`
`MODEL`
`APP_PASSWORD`

4. Запусти проект.
5. Открой выданный Replit URL на ПК или телефоне.

`PORT` можно оставить пустым: Replit передаст переменную окружения сам. Локально используется 3000.

# 🤖 РЕКОМЕНДУЕМЫЕ НАСТРОЙКИ

### Hugging Face

```env
PROVIDER=huggingface
HF_TOKEN=...
MODEL=openai/gpt-oss-120b:fastest
```

### OpenAI-compatible API

```env
PROVIDER=custom
OPENAI_BASE_URL=https://адрес-api/v1
OPENAI_API_KEY=...
MODEL=название-модели
```

### Ollama

```env
PROVIDER=ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434/v1
MODEL=название-модели
```

Для анализа изображений выбранная модель должна поддерживать vision/image input.

# ⛏️ MINECRAFT RCON

RCON — дополнительная функция. По умолчанию она не подключена.

Если действительно нужен RCON, настрой:

```env
APP_PASSWORD=сильный_пароль
RCON_HOST=адрес_сервера
RCON_PORT=25575
RCON_PASSWORD=пароль_RCON
```

Не публикуй RCON-порт напрямую в интернет без защиты.

# 📂 ДАННЫЕ

Пользовательские данные находятся в `data/`:

- `memory.json` — память
- `chats.json` — чаты
- `projects.json` — проекты
- `files.json` — сведения о загруженных файлах
- `uploads/` — загруженные файлы

При переносе TIMBLOGPLAY AI на другой компьютер перенеси папку `data/`, если хочешь сохранить свои чаты и память.

# 🛠️ ЕСЛИ ЧТО-ТО НЕ ЗАПУСКАЕТСЯ

1. Убедись, что установлен Node.js 20+.
2. Проверь, что `.env` существует.
3. Проверь правильность API-ключа.
4. Запусти `START.bat` ещё раз и посмотри текст ошибки в окне.
5. Если модель отвечает ошибкой, проверь название `MODEL` и выбранный `PROVIDER`.
