# TIMBLOGPLAY AI — GitHub / Online Launch

## Важно
GitHub сам по себе не запускает этот Node.js AI-сервер. GitHub используется как хранилище исходников. Для постоянной работы с телефона сервер нужно разместить на серверном хостинге, который подключается к GitHub.

В проект уже добавлен `render.yaml` для простого деплоя Node.js-приложения.

## 1. Загрузка в GitHub
1. Создай новый репозиторий на GitHub.
2. Вариант с ZIP: распакуй этот архив.
3. Загрузи **содержимое папки**, а не сам ZIP: `server.js`, `package.json`, `public/`, `data/`, `render.yaml`, `Dockerfile` и остальные файлы должны находиться в корне репозитория.
4. Никогда не загружай `.env` и реальные API-ключи.

## 2. Запуск онлайн
Подключи репозиторий к серверному хостингу, поддерживающему Node.js (например, через готовый `render.yaml`).

Параметры приложения:
- Build: `npm install --omit=dev`
- Start: `npm start`
- Port: используется переменная `PORT`, которую выдаёт хостинг.

Переменные окружения:
- `PROVIDER=huggingface`
- `HF_TOKEN=твой_секретный_ключ`
- `MODEL=openai/gpt-oss-120b:fastest`
- `APP_PASSWORD=твой_пароль`

Для другого провайдера смотри `.env.example` и README.md.

## 3. После деплоя
Хостинг выдаст HTTPS-адрес приложения. Открой его на телефоне или ПК.

На Android можно добавить сайт на главный экран браузера — тогда TIMBLOGPLAY AI будет ощущаться как отдельное приложение.

## 4. Локальный запуск на Windows
Установи Node.js 20+, распакуй проект, создай `.env` из `.env.example`, укажи ключ и запусти `START.bat`.

## 5. Безопасность
Если приложение открыто в интернете, обязательно установи непустой `APP_PASSWORD`. Не публикуй `.env`, токены, пароли RCON и другие секреты в GitHub.

## 6. Что означает «свой ИИ»
Этот репозиторий — собственное приложение и AI-агент TIMBLOGPLAY AI. Генерирующая модель подключается через выбранного провайдера. Это позволяет пользоваться им с телефона и ПК и позже подключить собственную модель через совместимый API.
